# 羁绊圣晶石计算器

FGO 羁绊圣晶石统计工具：导入 Chaldea 抓包导出的 `bond-detail` CSV，算出「还能领到多少颗圣晶石」。

## 使用

打开页面 → 拖入 CSV 或点击选择 → 查看结果 → 可导出结果图 / 明细表。

- 纯前端，所有计算在浏览器内完成，CSV 不会上传到任何服务器
- 单文件，零外部依赖，断网也能用（首次加载需联网）
- 支持日间 / 夜间主题

## 数据从哪来

需要先用 Chaldea 对游戏抓包，导出羁绊数据 CSV（表头含 `Name` / `Rarity` / `Rank` 即可，文件名不限）。

## 规则

- 6~9 绊按星级：5★ 各 3、4★ 各 2、3★ 各 1；2★ 仅 8-9 绊、1★ 仅 9 绊、0★ 按 1★
- 10 绊以上按已解锁的羁绊上限，每级 30 颗，15 绊封顶

要改规则，用文本编辑器打开 `index.html` 搜索 `REWARD_RULES`。

## 部署

本仓库即静态站点，直接由 GitHub Pages 托管，无需构建。
